====== Welcome to CCBC (Corny C Binary Converter) ====== 

This simple C application for Windows converts 8-bit decimal integers to binary.
I made it to experiment with GitHub & C, as I am a freshman at the University of Maine learning computer engineering, and I wanted to see if I could use code for our current coursework. I can.

This code is under the MIT license, so anybody is free to do whatever they want with it. I hope you learn from it the same way I did when I made it. Have fun, please.
